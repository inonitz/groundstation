# Run guide — integration/ (frozen MVD) + integration_notify/ (fork)

Copy-paste, absolute paths, no `cd`. `real` on a drone is HUMAN-run (the aircraft must be SECURED;
the assistant never fires motor commands). `mock`/`webcam` are safe desk tests.

---

## 0. Bring-up (both systems, before anything)
```bash
# derive the phone IP (WiFi gateway) and prove the chain is up
GW=$(ip route | awk '/^default/{print $3; exit}'); echo "phone=$GW"
curl -s "http://$GW:8080/status/" | head -c 200; echo          # want aircraft JSON, not 503
python3 /root/groundstation/scripts/test/dji_mock/probe_video.py "$GW" 5600 5   # want VIDEO LIVE
```
Phone: **API Server toggle ON**, app foregrounded (Android suspends it in the background).

## 0b. Kill switch (know it BEFORE arming)
1. **Aircraft power button, hold 3–5 s** — hardware cut, always works.
2. **Phone API Server toggle OFF** / force-close the app — drops our control authority.
3. **DJI CSC** (both sticks bottom-inner) — may be overridden while our virtual stick is active.
Software: say **"stop"** (halt) or **"manual"** (hand to RC).

## A. integration/ — the frozen, field-tested MVD (the main demo)

**Safe desk test (webcam + mock, no drone):**
```bash
# terminal 1: the mock control server
python3 /root/groundstation/scripts/test/dji_mock/mock_apiserver.py 127.0.0.1 8079
# terminal 2: the MVD (webcam video + mock control)
bash /root/groundstation/source/integration/run_mvd.sh webcam mock
```
**Drone video + mock control (safe — no motor commands):**
```bash
PHONE_IP=$GW bash /root/groundstation/source/integration/run_mvd.sh dji mock
```
**REAL flight (HUMAN-only; aircraft SECURED; prompts `ARMED`):**
```bash
PHONE_IP=$GW bash /root/groundstation/source/integration/run_mvd.sh dji real
```
Press **H** to talk. Verbs: `takeoff · land · spin · up/down · wave` (indoor-safe) ·
`forward/back/left/right · follow · look at me · come home` (outdoor/VPS). Emergency: **"stop"** / **"manual"**.
Questions → perception: **"what do you see" · "how many people" · "highlight the red backpack."**
Ctrl-C = full shutdown. (Skip gimbal verbs on stage — broken backend-side.)

## B. integration_notify/ — the fork (MVD + person-notify + dashboard)

**Prepare once (start + prewarm the VLM, check models):**
```bash
bash /root/groundstation/source/integration_notify/bootstrap.sh
```
**Webcam + notify (drone-free; the easy demo):**
```bash
NOTIFY_ATTRS="in a red shirt" bash /root/groundstation/source/integration_notify/run.sh
# dashboard: http://localhost:8090  (cv2 pane is the always-on fallback)
```
- Walk in wearing the attribute → 🔔 chat line + spoken alert + red box.
- Or arm by voice (press **H**): *"notify me when someone in a red shirt shows up."*
- Options: `NOTIFY_TRACKER=osnet` (appearance re-ID; needs `pip install torchreid`) ·
  `MVD_NO_ACTIONS=1` (perception-only, cuts all flight — the indoor "ask what it sees" demo) ·
  `NOTIFY_MIN_HITS=N` (debounce).

**Drone video + mock / REAL (same verbs as A, plus notify):**
```bash
PHONE_IP=$GW NOTIFY_ATTRS="in a red shirt" bash /root/groundstation/source/integration_notify/run.sh dji mock
PHONE_IP=$GW NOTIFY_ATTRS="in a red shirt" bash /root/groundstation/source/integration_notify/run.sh dji real   # HUMAN-only
```

**Still-image tool — run the vision on a photo → annotated image + log:**
```bash
python3 /root/groundstation/source/integration_notify/recognize.py <image> "<prompt>" [--detect "person,car"] [--notify "<attributes>"] [--mask] [-o out.jpg]
# examples:
python3 /root/groundstation/source/integration_notify/recognize.py /root/groundstation/img93.jpeg "describe the scene" --detect "person" --mask -o /root/groundstation/img93_out.jpg
python3 /root/groundstation/source/integration_notify/recognize.py /root/groundstation/img94.jpeg "highlight the person aiming the weapon" --mask -o /root/groundstation/img94_out.jpg
```
- `--detect person` = reliable YOLO boxes + SAM2 masks on every person (use for clear/crowd scenes).
- drop `--detect`, use a descriptive prompt = VLM grounding (use for occluded/smoky frames YOLO misses).
- `--notify "<attrs>"` = red MATCH box on people meeting the attribute. Writes `<out>` + `<out>_log.txt`.

## Fallbacks (rehearse once)
- **Fork misbehaves** → run `integration/` (section A) exactly as today. It is untouched.
- **Video stalls** → the watchdog auto-reconnects; else relaunch with `webcam` video.
- **Laptop mic flaky** → phone ASR (needs the recompiled APK) or retype.
- **Indoor, drone refuses lateral/vertical** → VPS can't lock (physics). Use yaw/spin/vertical/wave + perception.
- **:8080 / :5600 drop** → Android suspended the API Server. Foreground the app, re-toggle ON.
- **Anything scary** → kill switch (0b), power button first.
