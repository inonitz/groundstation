# closed/

Empty by design. Finished task docs land here just long enough to fold their findings into
`NOTES.md` / `ARCHITECTURE.md` / `ROADMAP.md`, then get deleted -- git history is the permanent
record, this folder is a working surface, not an archive. The folder itself stays (this file is
the placeholder git needs to track an empty directory) so `docs/README.md`'s bucket description
stays accurate even when nothing is currently closed-and-pending-deletion.
