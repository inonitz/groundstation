harden2 System Sketch

rev5, step 1. One owner thread for all app state (SYS1). Every input is a message into one inbox. Every blocking step runs on a worker. Redrawn 2026-10-06 from 01-system-sketch.md, section 10.

Teal lines are messages into the inbox. Grey lines are queues the main thread fills. Violet is HTTP or the SAM3 socket. Green dashed is a ROS2 topic. Amber is shared memory. The outside column lists the other processes.
