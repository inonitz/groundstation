harden2 Ponytail Sketch

rev5, step 1, the lazy version of the sketch: the same owner thread and the same hand-offs, built from the standard library and today's code. The cuts: the SAM3 process holds no slot, no process-event message, the phone's HTTP channel gone, the scheduler is a thread pool. From 01-system-sketch.md, section 11.

Teal lines are messages into the inbox. Grey lines are stdlib queues the main thread fills. Violet is HTTP or the SAM3 socket. Green dashed is a ROS2 topic. Amber is shared memory. Dotted is a plain variable the main thread reads each frame.
