Hy-MT2

86% overall, 96% commands, 72% perception, answer-mode 0. The best translator that fits the 8 GB card (1.2–1.5 GB) and runs ~2× faster than tgemma.

Keep for commands

DictaLM

99% commands, free on the CPU. Weak on perception (61%) and answers questions instead of translating. Heavy CPU tail.

90% overall, 98% commands, 88% perception — best of every model once given few-shots (the earlier 86%-command "collapse" was a zero-shot artifact). But 2,478 MiB still won't fit beside SAM3, so it is not deployable here.

Status & notes

Complete

Accuracy (413 cases, all quants), full-dataset and per-subset latency for all five GPU translators, DictaLM CPU thread sweep.

Q2_K: collapses

Self-quantized standard Q2_K (2.96 bpw, 741 MB) runs but produces incoherent output — "עלה עשרה מטרים" → "70 meters" repeated, system prompt leaking. A 1.8B model does not survive 2-bit. Not viable; Q4 (1,188 MiB) is the practical floor.

tencent low-bit: blocked on x86

1.25-bit needs PR #22836 (ARM NEON) and 2-bit needs PR #19357 (ARM SME2) — both unmerged, both ARM-only. This host is x86_64, so neither runs, on any llama.cpp build.
